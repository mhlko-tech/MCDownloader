الأسئلة الشائعةFrequently Asked Questions

ما هو برنامج MCDownloader؟

برنامج Windows لتنزيل صور فصول المانجا والمانهوا والكوميكس المتاحة داخل جلسة المتصفح المؤكدة، مع تنظيم الفصول وإدارة الأخطاء.

هل يدعم المواقع المختلفة؟

يستخدم ملفات تعريف مدمجة ومحرك كشف عام للتقسيم الرقمي، أزرار Load More، التمرير اللانهائي، روابط JSON والصور الكسولة، ويوفر Teach Site للتخطيطات غير المعروفة.

ماذا يحدث إذا فشل فصل؟

يستمر البرنامج إلى الفصل التالي، ويحفظ سجل الفشل محليًا مع المجلد الجزئي. تستطيع إعادة محاولة فصل واحد أو عدة فصول أو الجميع.

هل يعيد تنزيل الصور الناجحة؟

لا. يعيد استخدام الصور الجزئية الصحيحة، إلا إذا تغيرت قائمة الصور على الموقع، وعندها يعيد ضبط المجموعة الجزئية لذلك الفصل.

هل يتجاوز الحماية أو الفصول المدفوعة؟

لا. لا يتجاوز الدفع أو DRM أو تسجيل الدخول أو قيود العمر أو الفصول المقفلة. ينزّل فقط الصور المتاحة أصلًا في جلسة المتصفح التي أكدها المستخدم.

What is MCDownloader?

A Windows application for downloading manga, manhwa, and comic chapter images available in the confirmed browser session, with chapter organization and failure management.

Does it support different websites?

It combines built-in profiles with generic numeric pagination, load-more buttons, infinite scrolling, JSON links, lazy-loaded images, and a Teach Site mode for unknown layouts.

What happens when a chapter fails?

The queue continues to the next chapter and stores the failure locally with its partial folder. You can retry one chapter, selected chapters, or every failed chapter.

Does it download successful images again?

No. Valid partial images are reused unless the website's detected image list changes, in which case the partial set for that chapter is reset.

Does it bypass protection or paid chapters?

No. It does not bypass payment, DRM, login, age restrictions, or locked chapters. It downloads only images already accessible in the browser session confirmed by the user.
